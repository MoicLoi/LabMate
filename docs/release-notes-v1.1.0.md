# LabMate v1.1.0

> 实验智记 · 轻量教学实验助手
> 安装包：`LabMate-1.1.0.apk`（约 158 KB，Android 8.0+）
> 校验：见 `SHA256SUMS.txt`

## 这个版本做了什么

1.0 解决"把纸面表格变成 JSON"，1.1 开始解决"数据进来之后"的事。

### 派生列：少算一步，少错一次
模板列现在可以写表达式，例如滴定表的「消耗体积」：

```
消耗体积/mL | calc | v1 - v0 | 2
```

拍照识别、手工录入、粘贴文本都会自动重算；识别模型不再需要猜这一列，也就不会把 `24.52` 写成 `24.5` 或算错。称量表同样支持 `m1 - m0`。

### 描述统计：平行样合不合格，一眼看到
每张数据表下方自动给出数字列的 **n / 平均值 / 样本标准差 / 相对平均偏差（RAD）**，序号类列自动跳过。滴定三份平行样直接显示 `RAD = 0.06%`，不用再开计算器。

### 报告新增「数据处理」章
统计结果以三线表写入报告，并附 RAD 说明；章节编号改为动态生成，不会再出现"六、七、九"跳号。

### AI 快问
分支树解决"有标准路径的问题"，快问解决"没写进树里的问题"：在「分支」页或实验记录页提问，AI 结合实验名称与记录回答，答案可一键记入实验结论。

### 分支可编辑
分支库支持改标题、说明、类型和节点 JSON。内置树可以按自己的课程改，不用重新生成。

## 安装

1. 下载 `LabMate-1.1.0.apk`；
2. 允许"安装未知来源应用"后安装；
3. 打开 →「载入示例」可直接看一个完整的 NaOH 标定实验；
4. «更多 → 大模型设置» 填入任意 OpenAI 兼容接口与 Key，点「测试连接」。

不配模型也能用：流程记录、手动/粘贴建表、描述统计、公式、报告都不依赖网络。

## 验证情况

- Android 11 模拟器（WebView Chrome 83）实测安装、启动、拍照入库、分支、公式、报告、CSV 导出、返回键；
- 用本地 OpenAI 兼容 mock 服务跑通识别、分支生成、公式生成、AI 快问、步骤建议；
- 12 项 Node 单元测试覆盖 LaTeX 渲染、派生列求值、统计、报告编号；
- APK 使用 v2/v3 签名并通过 `apksigner verify`。

## 已知限制

- 识别质量取决于视觉模型与拍摄质量，务必人工复核（结果带置信度与 warnings）；
- 公式渲染是自研子集，不含矩阵、多行对齐、化学式；
- 分支是线性树，暂不支持回环/并行；
- 未做深色模式（旧 WebView 的 `prefers-color-scheme` 不可靠，先统一浅色）。

## 升级说明

数据仍保存在 `localStorage`（键 `labmate.v1`），覆盖安装不丢数据。内置模板的派生列只在**新安装**时生效；已有模板可在「预设表格 → 编辑」里把 `消耗体积` 改成：

```
消耗体积/mL | calc | v1 - v0 | 2
```
